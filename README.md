# Quaderno Pedalate

App per il telefono (Android e iPhone) che importa le uscite in bici da Strava o da file FIT/GPX/TCX e mostra statistiche, forma fisica (Fitness/Fatica/Forma) e consigli per migliorare.

- I dati restano sul telefono (IndexedDB). Backup e ripristino tramite file su Google Drive.
- Collegamento diretto a Strava: Client ID e Client Secret si inseriscono nell'app e restano sul telefono.
- Pubblicata con GitHub Pages: si installa dalla schermata Home.

Il sorgente è `src/app.html`; `python3 src/build.py` rigenera `index.html` e `sw.js`.

Indirizzo dell'app: https://pnicolo1-dot.github.io/quaderno.pedalate/
